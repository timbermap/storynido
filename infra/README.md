# infra/

Infraestructura como código con Terraform para Google Cloud.

Se completa en la **fase 02**: módulos reutilizables, ambientes `staging` y `production`, state remoto en GCS, cuentas de servicio de mínimo privilegio, buckets, Firestore, Cloud Run, Cloud Tasks, Pub/Sub, Workflows, Secret Manager, Artifact Registry, monitoreo, presupuestos y Workload Identity Federation para GitHub Actions.
